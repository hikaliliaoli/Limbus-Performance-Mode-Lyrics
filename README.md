# Limbus Performance Mode Lyrics

一款适用于网易云音乐 Windows 客户端的桌面歌词悬浮工具。它能把当前歌词显示在所有窗口上方，并提供具有逐字浮现、轻微抖动、升降和渐隐效果的“演出模式”。

> 当前为 `dev-0.1.0` 开发测试版，仅支持 64 位 Windows 10/11。本项目是非官方工具，与网易云音乐及相关游戏作品的开发商无隶属或授权关系。

## 下载与安装

1. 打开 [GitHub Releases](https://github.com/hikaliliaoli/Limbus-Performance-Mode-Lyrics/releases)。
2. 下载 `Limbus-Performance-Mode-Lyrics-dev-0.1.0-win-x64.zip`。
3. 将压缩包完整解压到任意文件夹。
4. 打开网易云音乐 Windows 客户端并播放歌曲。
5. 双击 `NeteaseLyricsOverlay.exe`。

发布包已经包含 .NET 运行环境，普通用户不需要安装 Python、Visual Studio 或 .NET SDK。不要直接在压缩包内运行程序，请先完整解压。

首次运行时 Windows SmartScreen 可能显示“未知发布者”。这是因为开发测试版尚未购买商业代码签名证书，不代表程序缺少运行环境。

## 快速使用

程序启动后不会显示普通设置窗口。请在 Windows 右下角托盘区域找到“网易云歌词悬浮层”图标，右键打开菜单。

- `歌词语言`：在原文和翻译之间切换；当前句没有翻译时会自动显示原文。
- `显示模式`：在标准模式与演出模式之间切换。
- `动画选择`：`0：无动画` 会让整句立即静态显示，但旧歌词仍会平滑渐隐；`1：Limbus演出` 使用逐字浮现、抖动、升降、倾斜和渐隐动画。
- `屏幕歌词数量`：同时显示 1～10 句歌词，默认 2 句。
- `锁定歌词位置`：取消锁定后可拖动标准模式中的每一条歌词；位置会自动保存。
- `字体与颜色`：导入字体、修改歌词颜色、整体字号和透明度。
- `字体与颜色 → 重点词`：开关重点词，并单独调整重点词颜色与 100%～200% 相对大小。
- `歌词提前/延后 0.5 秒`：歌词与声音有少量误差时进行校准。
- `退出`：完全关闭程序。

如果托盘图标没有显示，请点击任务栏右下角的 `^` 展开隐藏图标。

## 两种显示模式

### 标准模式

歌词在全屏透明舞台中按固定槽位显示，每一句都可以单独拖到喜欢的位置。达到显示数量上限后，新歌词会循环复用之前保存的位置。锁定后歌词恢复鼠标穿透，不会挡住游戏或其他程序的操作。

### 演出模式

歌词会出现在屏幕的不同位置，以轻微倾斜、升降、抖动和渐隐的方式逐字播放。屏幕达到歌词数量上限后，最早的一句会在新句播放后段逐渐消散。

## 重点词

程序会按每 3～5 句歌词自动选择两个重点词。选择完全在本机完成，同一首歌的结果保持稳定。

- 中文：按完整词语选择，不会随意截取半个词。
- 日语：选择连续汉字块或连续片假名块；像 `飲み込む`、`会いたい`、`眠れない` 这类动词，也可以只强调前面的单个汉字词干。除此之外，每累计 5 个含汉字的日语词，会额外选择 1 个汉字作为重点词。
- 英语：整个单词作为一个动画单位，不会拆成单个字母。

“整体字体大小”会同时缩放普通歌词、重点词和动画幅度；“重点词大小”是在整体缩放基础上的相对比例。

## 歌词来源与同步

程序优先从网易云本地播放日志读取精确歌曲 ID，再按该 ID 获取网易云原文和翻译。只有网易云没有可用歌词或请求失败时，才会使用 LRCLIB 作为备用来源。

程序不会读取网易云账号、密码或 Cookie，也不会向网易云客户端注入代码。它只读解析本地播放事件，用于识别切歌、播放、暂停、拖动进度及当前时间。

普通 LRC 通常只有每句时间，没有每个字的时间，所以逐字动画是在相邻歌词时间戳之间进行估算。个别歌曲仍可能需要使用“歌词提前/延后 0.5 秒”微调。

## 常见问题

### 一直显示“等待网易云音乐播放”

- 确认使用的是网易云音乐 Windows 桌面客户端。
- 先开始播放歌曲，再启动本程序。
- 如果网易云以管理员身份运行，本程序也需要以管理员身份运行。

### 提示“歌词悬浮层已经在运行”

程序可能仍在托盘后台运行。展开隐藏的托盘图标，右键歌词悬浮层并选择“退出”，再重新启动。

### 歌词完全看不见

右键托盘图标，进入 `字体与颜色 → 歌词透明度`，确认透明度不是 0%。

### 没有翻译

选择翻译模式后，没有翻译的句子会自动显示原文。部分歌曲本身没有网易云翻译。

### 想恢复默认设置

配置文件位于：

```text
%LOCALAPPDATA%\NeteaseLyricsOverlay\config.json
```

先退出程序，删除该文件，再次启动即可生成默认配置。导入的字体位于同一配置目录。
